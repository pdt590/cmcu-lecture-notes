## Lưu ý

- Lập team ít nhất `5 người`
- Báo cáo project sẽ bao gồm
  - Source code (`upload lên github, lưu ý: không yêu cầu nén code`)
  - Báo cáo:
    - Bản mềm dùng [MẪU BÁO CÁO](./cmcu-project-report-temp.doc) (`upload lên github`)
    - Bản cứng (`Nộp cho giảng viên`)
  - Slide trình bày (`upload lên github`)
  - Video demo (`Chỉ gửi link lên github`)
- Đại diện team `gửi link github báo cáo` cho giảng viên, khi có yêu cầu
- Lưu ý:
  - Đọc kỹ yêu cầu nội dung báo cáo
  - Nội dung `slide` trình bày ít nhất bao gồm (Trình bày `15 min`)
    - Tên đề tài
    - Thành viên nhóm và mức độ đóng góp của mỗi thành viên theo % (tổng `100%`)
    - Miêu tả các thư viện, công nghệ, design patterns (nếu có) đã sử dụng
    - Trình bày các giao diện và chức năng tương ứng
    - Chạy demo
